\section{\underline{Analýza metódy}}
\begin{justify}
    

    Lagrangeova interpolácia je numerická metóda používaná na aproximáciu neznámych hodnôt funkcie na základe známych hodnôt v určitých bodoch. Úlohou aproximácie funkcie je nahradenie reálnej funkcie\hspace{0.4cm} $\textbf{\textit{f : A}} \to \mathbb{R}$ \hspace{0.4cm}pomocou funkcie $ \hspace{0.4cm}\textbf{\textit{g : A}} \subseteq \textbf{\textit{B}} \to \mathbb{R}$\hspace{0.4cm}za predpokladu, že musia mať rovnaké fukčné hodnoty v známych \textbf{\textit{n} + 1} rôznych bodoch 
    \textbf{\textit{$x_0,x_1,ldots,x_n$}}. Tieto hodnoty môžu byť napríklad výsledkom merania. Dôvodom aproximácie funkcie je zvyčajne neznalosť presného predpisu funkcie \textbf{\textit{f(x)}} alebo naopak príliš zložitý predpis pre ďalšie použitie. Lagrangeov interpolačný polynóm nahradzuje reálnu funkciu \textbf{\textit{f(x)}} polynómom tak, aby sa zachovali rovnaké funkčné hodnoty v známych rôznych bodoch.  \\
\end{justify}
   
    
    
 \begin{justify}   
    Predpokladajme, že máme \textbf{\textit{n} + 1} hodnôt \textbf{\textit{$f(x_0),f(x_1),ldots,f(x_n)$}} 
    funkcie \textbf{\textit{f(x)}} v rôznych bodoch\\ \textbf{\textit{$x_0,x_1,ldots,x_n$}} na intervale $\langle$\textbf{\textit{a,b}}$\rangle$. Pomocou bodov \textbf{\textit{$x_i$}}, ktoré nazývame aj uzlové body, definujeme Lagrangeove bázické polynómy $\ell_i(x)$ v tvare:
\end{justify}
    
        \[\ell_j(x) = \frac{(x - x_0)\cdots(x - x_{j-1})(x - x_{j+1})\cdots(x - x_n)}{(x_j - x_0)\cdots(x_j - x_{j-1})(x_j - x_{j+1})\cdots(x_j - x_n)},\hspace{0.4cm} pre \hspace{0.4cm}\textbf{\textit{j}} = 0,1, ... ,\textbf{\textit{n}}.\] 
      \\
    resp. v skrátenej forme:

        \[\ell_j(x) = \prod _{i=0,\,i\neq j}^{n}\frac{x-x_i}{x_j-x_i}\]
    \\
    Lagrangeov interpolačný polynóm $n$ - tého stupňa definujeme:

        \[L(x):=\sum _{j=0}^{n}y_{j}\ell _{j}(x)\]
    Táto metóda sa teda používa na vypočítanie funkčných hodnôt bodov vo vnútri vstupného intervalu funkcie, pre ktoré túto hodnotu nepoznáme.

// vypocet hodnoty interpolacneho polynomu v Lagrangeovom tvare v bode x
double LagrangeInterpol(int *data_x, double *data_y, int n, double x)
{
    double lag,lag_pol=0;
    int j,i;
    for(j=0; j<n; j++)
    {
        lag=1.0;
        for(i=0; i<n; i++)
        {
            if(i == j) continue;
            // vypocet Lagrangeoveho bazoveho polynomu
            lag *= (x - data_x[i]) / (data_x[j] - data_x[i]) ; 
        }
        lag_pol += data_y[j] * lag; // vysledna suma bazovych polynomov
    }
    return lag_pol;
}

void heapfy(int data[], int N, int i)
{
    int naj = i;
    int lavy = 2*i + 1;
    int pravy = 2*i + 2;

    if(lavy < N && data[lavy] > data[naj])
    {
        naj = lavy;
    }
    if(pravy < N && data[pravy] > data[naj])
    {
        naj = pravy;
    }
    if(naj != i)
    {
        swap(data[i], data[naj]);
        heapfy(data, N, naj);
    }
}

void HeapSort(int data[], int N)
{
    for(int i = N/2 - 1; i >= 0; i--)
    {
        heapfy(data, N, i);
    }
    for(int i = N - 1; i > 0; i--)
    {
        swap(data[0], data[i]);
        heapfy(data, i, 0);
    }
}

\section{\underline{Záver}}
    \normalsize
Presnosť numerickej metódy interpolácie pomocou Lagrangeovho interpolačného polynómu je závislá na stupni vstupného polynómu. Pri vyšších stupňoch polynómu vznikajú odchýlky od pôvodnej funkcie vo vnútri intervalu. Toto potvrdzujú aj nami vypočítané hodnoty v tabuľke pre polynóm 9-teho stupňa (viď \hyperlink{tab-lagrange}{Tabuľka 2}).\\
Pre hodnoty mimo intervalu interpolovanej funkcie chyba aproximácie rýchlo rastie, keď sa $x$ vzďaľuje od $x_0$ doľava alebo od $x_n$ doprava. Toto sme overili pokusným meraním časov pre hodnoty mimo intervalu interpolovanej funkcie a ich porovnaním s najbližšími interpolovanými hodnotami v tabuľke (\hyperlink{tab-porovnanie}{Tabuľka 3}). \\ \\
